# Source provenance

This repository extracts a completed read-only evidence workflow from a private working repository. The source commit is `1a891c5609488da0ef8e65256fd92150718de52c`. The original repository URL, operating instructions, memory, research artifacts, client files, credentials, and production configuration are omitted.

[source-provenance.json](source-provenance.json) records every selected original file's SHA-256 and its extracted SHA-256. Files came from Git blobs at that commit, rather than arbitrary working-tree contents. The original CLI, evaluation, mapping, bank, receivables, review, and HTML modules are retained. The `acfr_factory` package name preserves the original imports and code-hash lookup paths.

Extraction changes are limited to:

- Keeping only `canonical_json` and `fingerprint` in `link_contract.py`; unrelated native-system link helpers are omitted.
- Removing factory-only imports, setup helpers, and integration cases from the seven selected unittest files.
- Updating package and test descriptions to match the standalone boundary.
- Adding packaging, CI, a demo runner, and these public documentation files.
- Replacing the source example README, whose instructions and links depended on the private repository.
- Capturing the rendered missing-rent synthetic review in `review-example.png`; retained JSON and HTML are regenerated by the demo.

The original selected source files contain no copyright header or license grant. None was removed. This extraction does not add an open-source license; see [NOTICE.md](../NOTICE.md).

## Validation boundary

The standalone native oracle is `python3 -m unittest discover -s tests -q`. It contains 175 authored synthetic checks after removal of the factory consumer cases. The demo invokes the actual CLI on copied fixtures and checks expected results, an intentional unresolved case, and replay after source removal.

The earlier private adoption receipt identifies the implementation commit but is outside that commit and is not imported as a current proof artifact. Current runnable evidence comes from this repository's own tests and demo. Original wider-system test counts, browser reviews, native-system readiness, production results, and savings are not claimed here.

The retained fixtures and test expectations were prepared within the same development lineage as the implementation. Their successful evaluation establishes conformance to those authored cases. It does not establish independent accounting review, authentic underlying documents, complete populations, or general accounting correctness.

The first hosted matrix exposed an incorrect Python 3.10 minimum in the extraction's package metadata. The retained date-parsing behavior requires Python 3.11 or later. Packaging, quickstart and CI now declare that minimum; the original evaluator and its compact-date regression case remain unchanged.
